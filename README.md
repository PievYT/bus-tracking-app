Bussing app --- Backend
A starter user interface  for a school bus tracking app

What will be included in this MVP (Minimum Viable Product)
1. FastAPI Rest API with interactive docs
2. SQLAlchemy models, for schools, students, teachers etc
3. UUID identifiers and database constraints
4. SQLite by default for an easy local starthurt (to host this MVP on your PC) via DATABASE\_URL when it is configured
5. A basic testing procedure
6. Seed script with demo data

NOTE THAT THIS IS A MVP (MINIMUM VIABLE PRODUCT) WHICH MEANS THIS IS IN NO WAY READY FOR ANY REAL STUDENT DATA
